# Prompts Trendseeker

**Herramienta fija: Google Gemini** (no Midjourney).

Aplica a:
- cualquier **marca** o **producto** que maneje Trendseeker
- prompts de **videos** y piezas de producto / lifestyle

No confundir con ECR: las portadas de newsletter ECR van en Midjourney (`index/clientes/ecr/newsletter/`).

## Convención
1. Adjuntar fotos de producto reales como referencia.
2. Prompt en español (o bilingüe si hace falta), pensado para Gemini.
3. Énfasis en fidelidad al producto (silueta, color, detalles).
4. Guardar cada prompt en esta carpeta como `.txt` listo para pegar.
