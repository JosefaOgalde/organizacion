# Prompts Trendseeker

**Herramienta fija: Google Gemini en modo VIDEO** (no imagen fija; no Midjourney).

Aplica a:
- cualquier **marca** o **producto** que maneje Trendseeker
- prompts de **videos** y piezas de producto / lifestyle en movimiento

No confundir con ECR: las portadas de newsletter ECR van en Midjourney (`index/clientes/ecr/newsletter/`).

## Convención
1. Adjuntar fotos de producto reales como referencia.
2. Prompt pensado para **video** en Gemini (si responde “solo puedo generar videos”, el prompt debe ser de video).
3. Énfasis en fidelidad al producto (silueta, color, logo/parche, herrajes, suela).
4. Guardar cada prompt en esta carpeta como `.txt` y registrarlo en `indice.json`.
