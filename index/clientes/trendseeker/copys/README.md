# Copys video · Trendseeker

**Reglas obligatorias**
1. **Primera línea = contexto** de la escena/video (qué se ve / mood), no solo specs.
2. **Emojis obligatorios** en esa línea de contexto y en el cuerpo del copy.
3. Después sí: producto + características reales de ficha (sin inventar).
4. Link de shop + hashtags.

Ejemplo de estructura:
```
[línea de contexto + emojis]

[producto / características]

👉 link

#hashtags
```
