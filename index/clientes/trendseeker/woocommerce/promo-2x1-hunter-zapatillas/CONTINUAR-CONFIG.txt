PASO 1 — Sección DISCOUNT (la que dice «Select Types» / Get Y)
----------------------------------------------------------------
1) En el desplegable «Select Types» / Get Y Discount Type elegí:

   → Buy X get Y - All
     (en español puede verse como: «Buy X get Y - Todos» / «Comprar X obtener Y - Todos»)

   Si NO aparece esa opción, la regla se creó con otro tipo.
   Solución: Volvé a «Reglas de descuento» → Add New Rule → tipo
   «Buy X Get Y» / «Comprar X obtener Y» y repetí el filtro.

2) Cuando se abran los campos de Get Y, completá exactamente:

   Contar cantidades como / Count quantities as:
     → Filter set above
       (o «Filtro establecido arriba» / «Los productos del filtro juntos»)

   Modo de aplicación / Mode of apply:
     → Cheapest
       (o «Más barato» / «El más barato»)

   Cantidad mínima / Minimum quantity:
     → 2

   Cantidad máxima / Maximum quantity:
     → (dejalo vacío)

   Cantidad gratis / Free quantity:
     → 1

   Tipo de descuento / Discount type:
     → Free
       (o «Gratis»)
     Alternativa si no hay Free:
     → Percentage / Porcentaje → 100

   Recursive / Recurrente:
     → NO / desactivado
       (para la prueba: solo 1 gratis aunque lleven 4)

3) NO hace falta elegir productos “Get Y” aparte si usaste «Buy X get Y - All»:
   el gratis sale del mismo set (zapatillas Hunter).


PASO 2 — Sección REGLAS (opcional) — casi no toques nada
---------------------------------------------------------

Límite de uso máximo: Unlimited (está bien para la prueba).

Válido desde / Válido hasta: vacío (o poné solo hoy→mañana si querés acotar).

Condiciones populares (izquierda):
  → NO agregues «Cantidad de artículos por línea»
  → NO agregues Subtotal / Cupón / etc. para esta prueba

  La cantidad «2» ya la define Minimum quantity = 2 en Discount.
  Si sumás condición de cantidad, puede romper o duplicar lógica.
