Qué vas a hacer (mapa de 6 pasos)

Checklist de la entrega

1Abrir el flujo

En n8n, abrir el workflow que hoy termina en Google Sheets.

2Crear credencial MySQL

Una sola vez: host, puerto, usuario, clave, base de datos.

3Agregar nodo MySQL

Buscar “MySQL” en el panel de nodos y soltarlo en el canvas.

4Ponerlo ANTES de Sheets

Mover el nodo a la izquierda de Google Sheets y reconectar cables.

5Configurar INSERT / UPDATE

Elegir tabla + mapear campos desde el nodo anterior.

6Probar y guardar

Execute step → revisar fila en MySQL → luego Sheets → Save.

No borres el nodo Google Sheets. Solo lo dejas después de MySQL.

Paso 3 Agregar el nodo MySQL al canvas

Todavía no lo conectes · primero créalo

  1. En el canvas, clic en el + (Add node).
  2. Escribe MySQL en el buscador.
  3. Elige el nodo MySQL (oficial).
  4. En Credential, selecciona la credencial del Paso 2.

MySQL a la izquierda · Sheets a la derecha.

  1. Arrastra el nodo MySQL a la izquierda de Google Sheets.
  2. Borra el cable viejo que iba directo a Sheets (clic en el cable → Delete).
  3. Conecta: nodo anterior → MySQL → Google Sheets.

Lee el canvas de izquierda a derecha: MySQL siempre antes que Sheets.

Paso 5 Configurar qué guarda MySQL

Tabla + columnas · con datos del nodo anterior

En el nodo MySQL

  1. Operation: Insert (o Insert or Update).
  2. Table: elige la tabla (ej. leads, registros).
  3. Columns / Values: mapea cada campo.

Cómo mapear

  1. En cada valor, usa la expresión del nodo anterior.
  2. Ejemplo: {{ $json.email }}
  3. Incluye fecha: {{ $now }} si aplica.
Columna
Valor desde n8n (ejemplo)

{{ $json.email }}

{{ $json.nombre }}

{{ $json.origen }}
created_at
{{ $now.toISO() }}
Tip: primero haz Insert simple. Upsert (actualizar si existe) viene después, cuando la clave única esté clara.

Las columnas deben existir en MySQL. Si falta una, créala en la base antes (phpMyAdmin / DBA).

Paso 5b Dejar Google Sheets alimentado después

Sheets no se elimina · solo cambia de posición

  1. Abre el nodo Google Sheets (sigue al final).
  2. Revisa que la operación sea Append / Update como antes.
  3. Si los campos vienen del nodo anterior a MySQL, puedes seguir mapeando desde ahí o desde la salida de MySQL.
  4. Lo importante: el cable llega a Sheets después de MySQL.

Orden final del flujo.

Si MySQL falla, Sheets no debería escribir “como si nada”. Deja el cable en serie (no en paralelo) para eso.

Serie = un cable detrás del otro. Paralelo = dos cables desde el mismo nodo (evitar aquí).

Paso 6 Probar, verificar y guardar

Cómo saber que quedó bien

En n8n

  1. Clic en el nodo MySQL → Execute step.
  2. Debe salir verde / success.
  3. Luego Execute del flujo completo (o Test workflow).
  4. Save el workflow.

Verificación fuera de n8n

  1. MySQL: mira la tabla (phpMyAdmin / cliente SQL) — debe haber fila nueva.
  2. Sheets: debe aparecer la fila después.
  3. Si MySQL no tiene fila pero Sheets sí → el orden está mal.
SeñalQué significaQué hacer
MySQL OK · Sheets OKListoGuardar y documentar
MySQL falla · Sheets vacíoCredencial / tabla / columnasRevisar Paso 2 y 5
Sheets OK · MySQL vacíoOrden incorrectoVolver al Paso 4

Entregable: captura del canvas con MySQL a la izquierda de Sheets + fila en MySQL.

Errores comunes (y cómo evitarlos)

Léelo antes de entregar

ErrorPor qué pasaFix rápido
MySQL a la derecha de Sheets Se agregó el nodo pero no se reordenó Paso 4: mover + reconectar
Access denied / ECONNREFUSED Host, clave o firewall Probar credencial; pedir IP allowlist de n8n
Unknown column El mapeo usa un campo que no existe en la tabla Alinear nombres con phpMyAdmin
Sheets escribe aunque MySQL falle Nodos en paralelo Un solo cable en serie
Duplicados en MySQL Insert sin clave única Usar Insert or Update + unique key

Si dudas: captura el canvas y el error rojo del nodo MySQL — con eso se diagnostica en 1 minuto.
