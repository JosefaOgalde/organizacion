# Clínica Indisa — Prospecto MKOF

Documentos y plantillas del prospecto viven **dentro de cada módulo**:

```
clinica-indisa/
├── index.html          ← hub (elige módulo)
├── RRSS/               ← redes orgánicas
│   ├── plantillas/     ← patrones de referencia (formato)
│   ├── data/
│   └── laminas/        ← entregables Canva
└── UX-UI/              ← diagnóstico web
    ├── plantillas/     ← referencia de formato
    ├── data/
    └── laminas/        ← entregables Canva
```

## Abrir

| Qué | URL |
|-----|-----|
| Hub clínica | `http://127.0.0.1:8000/index/clientes/mkof/prospecto/clientes/clinica-indisa/?disco=1` |
| RRSS | `…/clinica-indisa/RRSS/?disco=1` |
| UX/UI | `…/clinica-indisa/UX-UI/?disco=1` |

## Módulos

- **RRSS** — ecosistema, engagement, oportunidades, conclusiones vs CLC / Alemana / Dávila / Santa María.
- **UX/UI** — diagnóstico web (PageSpeed, navegación, referentes, recomendaciones, Ley 21.719).

Plantillas = solo referencia de formato. El diagnóstico y las láminas reflejan el **hoy**.
