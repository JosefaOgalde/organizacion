# Patrones etapa 1

Láminas de referencia para el análisis de prospectos (RRSS orgánicas).

Recreación fiel del layout de la presentación (cream + verdes). Al trabajar un prospecto concreto, se copian a `../clientes/<slug>/RRSS/plantillas/` y los entregables se rellenan en `../clientes/<slug>/RRSS/laminas/` con data de `RRSS/data/`.

| Archivo | Lámina |
|---------|--------|
| `01-ecosistema-rrss.png` | Matriz ecosistema |
| `02-ecosistema-competencia.png` | Formatos / temáticas / periodicidad |
| `03-oportunidades.png` | Tres oportunidades |
| `04-conclusiones.png` | Cuadrantes + CONCLUSIONES |

Si tienes los PNG originales de Canva/PPT, puedes reemplazar estos archivos manteniendo los mismos nombres.
