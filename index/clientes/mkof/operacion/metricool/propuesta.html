2. Punto clave: la API

La API de Metricool (Zapier, Make.com y acceso API) solo está en Advanced / Custom. En Starter no se puede conectar.

Útil para

  • Métricas / reportes hacia Make o n8n
  • Alertas o cierre de mes automatizado
  • Unificar RRSS con otras herramientas

Criterio

Pagar Advanced por la API solo si hay un flujo concreto en los próximos meses. Si no, Starter y subir después.

3. Qué conservar vs qué decidir

Esencial (ambos escenarios)

  • Programar y publicar
  • Analítica e historial
  • Informes PDF / PPT
  • LinkedIn cuando aplique

A decidir

  • Conectar la API → Advanced
  • Roles / aprobaciones de equipo
  • Looker Studio
  • 15+ marcas en paralelo

4. Comparativa (pago anual, USD)

Referencia pública Metricool (ago 2026). El pago anual suele ahorrar hasta ~24% vs mensual. Verificar monto exacto en la cuenta.

Dos rutas: (1) Ahorro → Starter 5 anual (~USD 240) sin API. (2) API + automatización → Advanced 15, activar API y un flujo piloto en Make/n8n. Si el plan actual ya incluye API, puede bastar con conectar (no subir de plan).

5. Antes de cambiar el plan

  • Contar marcas conectadas; desconectar las inactivas si vamos a Starter 5.
  • Confirmar si el plan actual ya incluye API y solo falta activarla.
  • Confirmar que solo opera CM (equipo = Advanced).
  • Revisar add-ons (X/Twitter, Advanced Analytics) y quitar lo que no se use.
  • El downgrade suele aplicarse al final del ciclo de facturación.

6. Pedido

Necesito definición:

  1. ¿Bajamos a Starter 5 (ahorro, sin API)? o
  2. ¿Advanced / plan con API para conectar y automatizar?

Con esa respuesta avanzo el cambio en la cuenta y, si aplica, la conexión de la API.
