---

## 1. Situación actual

| Ítem | Detalle |
|------|---------|
| Herramienta | Metricool (gestión e informes de RRSS) |
| Gasto aproximado | **~USD 500 / año** |
| Problema | El plan actual supera lo que necesitamos con el número de clientes activos hoy |
| Objetivo | Alinear costo al volumen real **sin cerrar la puerta a automatizar vía API** si eso aporta valor |

Metricool cobra por **marcas** (cada cliente/marca = 1 brand), no por usuario. Si bajamos de clientes, conviene bajar de plan — **salvo** que queramos funciones que solo vienen en Advanced (API, equipo, Looker Studio).

---

## 2. Qué necesitamos seguir haciendo

- Programar y publicar en redes de los clientes activos  
- Revisar métricas e historial  
- Generar / descargar informes (PDF/PPT) para el reporte mensual  
- Conectar LinkedIn cuando aplique  

**Opcional / a decidir:** conectar la **API de Metricool** para automatizar (Make, Zapier, n8n, reportes custom).

---

## 3. Punto clave: la API

Según Metricool, la **API** (Zapier, Make.com y acceso API) está disponible en planes **Advanced y Custom**. **No está en Starter ni en Free.**

| Si elegimos… | ¿API? | Implicancia |
|--------------|-------|-------------|
| Starter 5 o 10 | No | Máximo ahorro; todo manual / exports PDF-PPT |
| Advanced 15+ | Sí | Podemos conectar API y automatizar flujos |

### Para qué servirían conectar la API (ejemplos MKOF)

- Sacar métricas o resúmenes hacia **Make / n8n** sin bajar PDF a mano  
- Disparar alertas o reportes internos cuando cierren el mes  
- Unificar datos de RRSS con otras herramientas del stack  

**Criterio:** solo vale la pena pagar Advanced por la API si vamos a usarla de forma concreta en los próximos meses. Si no hay un flujo definido, conviene Starter y revisar después.

## 5. Recomendación (dos escenarios)

### Escenario 1 — Priorizar ahorro (recomendado si no hay flujo API listo)

**Pasar a Starter · hasta 5 marcas · facturación anual (~USD 240/año).**

1. Con pocos clientes activos, **5 marcas alcanzan**.  
2. Conservamos publicación*, LinkedIn, historial e informes PDF/PPT.  
3. Ahorro claro vs ~USD 500.  
4. Si más adelante definimos automatización, **subimos a Advanced** y recién ahí conectamos la API.

### Escenario 2 — Priorizar API / automatización

**Quedarnos o pasar a Advanced · 15 marcas** y **activar la API**.

1. Habilitar token / conexión API en Metricool.  
2. Definir 1–2 flujos piloto (ej. reporte mensual → Make/n8n).  
3. Revisar en 60–90 días si la API se usa; si no, bajar a Starter.

\*Sujeto a política de uso justo de Metricool.

### Condiciones a chequear antes del cambio

- [ ] Contar marcas conectadas hoy (si hay >5 y vamos a Starter, archivar/desconectar inactivas).  
- [ ] Confirmar si el plan actual ya incluye API y solo falta conectar.  
- [ ] Confirmar si alguien más del equipo entra a la cuenta (equipo = Advanced).  
- [ ] Revisar add-ons (X/Twitter ~USD 10/mes por cuenta; Advanced Analytics) y cancelar lo que no se use.  
- [ ] El downgrade suele aplicarse **al final del ciclo de facturación** actual.
