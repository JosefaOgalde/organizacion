CRC · Carga recetas Cencosud

Scraping local → completar BM

Se hace en tu PC con tu usuario de Business Manager. No hace falta otra máquina: Chromium se abre en tu pantalla (ADFS / MFA a mano si pide).

  1. 0. Una vez — Playwright + .env pip install playwright · playwright install chromium
    Copia carga-recetas-cencosud/secrets/env.example → secrets/.env y pon tu usuario.
  2. 1. Word en inbox + parse python scripts/parse-receta-word.py …/inbox/archivo.docx
  3. 2. Explorar / mapear el formulario (con tu login) python scripts/explorar-bm-cencosud.py
    Entras en la ventana → abres «Nueva receta» → ENTER en la terminal.
  4. 3. Completar la información en la interfaz python scripts/publicar-receta-cencosud.py …/out/receta.json --headed --dry-run
    Revisa en el BM; cuando esté bien, publica (sin --dry-run).
