CRC · Carga recetas Cencosud

Scraping local → completar BM

Se hace en tu PC con tu usuario de Business Manager. Acepta Word o PDF Jumbo (ej. Maremoto.pdf). Chromium se abre en tu pantalla (ADFS / MFA a mano si pide).

  1. 0. Una vez — Playwright + .env pip install playwright · playwright install chromium
    Copia carga-recetas-cencosud/secrets/env.example → secrets/.env y pon tu usuario.
  2. Un clic Arrastra el Word o PDF a CARGAR-RECETA-BM.bat (raíz del repo).
    Ejemplo: CARGAR-RECETA-BM.bat "%USERPROFILE%\Downloads\Maremoto.pdf"
  3. 1a. Parse Word o PDF Jumbo python scripts/parse-receta-word.py …/inbox/Maremoto.pdf
  4. 1b. O JSON de 5 bloques (cualquier receta) Copia bloques-receta.template.json → bloques/mi-receta.json
    python scripts/expandir-bloques-receta.py bloques/mi-receta.json
    Guía: carga-recetas-cencosud/BLOQUES-RECETA.md
  5. 2. Scraping / mapear el formulario (con tu login) python scripts/explorar-bm-cencosud.py --reuse-session
    Entras en la ventana → abres la receta (5 bloques al centro) → ENTER en la terminal.
  6. 3. Completar la información en la interfaz python scripts/publicar-receta-cencosud.py …/out/maremoto.json --headed --dry-run
    Revisa en el BM; cuando esté bien, publica (sin --dry-run).
