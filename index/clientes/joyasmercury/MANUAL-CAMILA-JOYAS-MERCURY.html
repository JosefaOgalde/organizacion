3. Manuales

3.1 Descuentos y cupones

  1. WooCommerce → Ajustes → General → activar cupones → Guardar.
  2. Marketing → Cupones → Añadir cupón.
  3. Código (ej. MERCURY10) · tipo · importe · caducidad → Publicar.

Video: Tutorial WooCommerce principiantes

3.2 Menú y categorías

  1. Productos → Categorías (crear/editar).
  2. Apariencia → Menús → añadir categorías/páginas → Guardar menú.

Video: Cómo crear un menú en WordPress

3.3 Subcategorías

  1. Productos → Categorías → Añadir nueva.
  2. Categoría superior = madre (ej. Esencial) → Añadir.

Video: WooCommerce 2025 (productos/categorías)

3.4 Que la categoría nueva aparezca en el menú

  1. Apariencia → Menús.
  2. Marcá la categoría → Añadir al menú → ordenar → Guardar.

Crear la categoría no la pone sola en el menú: hay que agregarla.

3.5 Editar la página de inicio

  1. Páginas → Inicio → Editar con Elementor.
  2. Cambiar textos/bloques → Actualizar.

No borrar clases jm-home-novedades / jm-circulos-categoria.

Video: Editar con Elementor

3.6 Fotos de productos y banners

  1. Producto → Imagen del producto / Galería → Actualizar.
  2. Banner: Smart Slider o imagen en Elementor → reemplazar → Actualizar.

Ayuda Smart Slider: docs

3.7 Revisar y gestionar pedidos

  1. WooCommerce → Pedidos.
  2. Abrir pedido → cambiar estado (Procesando → Completado) → Guardar.

Doc: Managing orders · Video: Proceso de compra / pedidos
