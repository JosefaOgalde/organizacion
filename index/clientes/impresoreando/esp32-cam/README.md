# ESP32-CAM — Impresoreando

Guía completa: [`docs/impresoreando/ESP32-CAM.md`](../../../docs/impresoreando/ESP32-CAM.md)

## Sketch

Carpeta: `CameraImpresoreando/`

1. Copiá `secrets.h.example` → `secrets.h` (si aún no existe).
2. Completá Wi‑Fi **2,4 GHz**.
3. Arduino IDE → placa **AI Thinker ESP32-CAM** → Subir.
4. Monitor serie 115200 → abrí la IP que imprime.
