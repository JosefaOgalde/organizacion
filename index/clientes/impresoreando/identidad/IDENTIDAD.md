# Impresoreando — identidad visual

## Archivos oficiales

| Archivo | Uso |
|---------|-----|
| `logo-ima2.png` | **Default en UI** (wordmark · `?v=ima2-claro-1`). Landing, panel, venta, catálogo |
| `logo-ui-custom.*` | **Override** subido con botón **Editar logo** (landing/panel). API `POST /api/cliente-logo` |
| `logo-oficial.png` / `logo-marca.png` | Versiones anteriores (caché vieja; no usar en UI) |
| `logo-impresoreando-claro.png` | Misma arte que `logo-ima2` (fuente del archivo vigente) |
| `logo-impresoreando-transparente.png` | Wordmark transparente (alternativa) |
| `logo-impresoreando-oscuro.png` | Sobre negro |
| `logo-impresoreando-fuente.png` | Canvas original 1536×1024 (respaldo; no usar en UI) |
| `logo-impresoreando.svg` | Aproximación vectorial de apoyo |
| `icono-corto-impresoreando.svg` | Ícono corto |

**Regla:** no inventar la marca con Midjourney/Gemini. Preferí **Editar logo** en la landing/panel para subir el PNG correcto. Si editás a mano la carpeta, usá **nombre de archivo nuevo** + bump `?v=` en landing/panel/catálogo.
