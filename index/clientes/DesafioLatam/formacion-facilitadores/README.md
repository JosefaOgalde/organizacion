# Certificado Formación para Facilitadores

Plantilla digital para acreditar la aprobación de la **Formación para Facilitadores** de Desafío Latam. Pensada para carga y emisión posterior en LMS Empieza o Proyecto.

## Cómo se usa

1. Abrir `Formacion-Facilitadores.html` en Laravel (`http://127.0.0.1:8000/…`).
2. Revisar la maqueta y probar nombres cortos / extensos.
3. Descargar **PNG fondo LMS** para subir a la plataforma (sin nombre ni fecha).
4. Posicionar los overlays según `identidad/ESPECIFICACION-LMS.md`.

La maqueta SVG sirve para validar diseño con el cliente. El fondo SVG/PNG es el archivo de carga.
