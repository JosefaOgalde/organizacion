# Prompt de diseño · Estética desafiolatam.com → slides

Fuente visual: https://desafiolatam.com/ (landing B2B · ago 2026)

Usá este bloque como **sistema de diseño** al generar o rediseñar cualquier slide de la presentación ADL.

```
Diseña UNA slide de presentación corporativa B2B imitando la estética del sitio web desafiolatam.com.

── ESTÉTICA GENERAL ──
Limpia, moderna, tech-educativa, mucho aire. Look landing B2B premium, no PowerPoint genérico.
Fondo principal: blanco puro #FFFFFF.
Sin degradados pesados, sin texturas ruidosas, sin sombras dramáticas.

── PALETA (tomada del sitio) ──
- Fondo: #FFFFFF
- Texto principal / charcoal: #0F1722 (casi negro azulado)
- Verde acento Desafío (highlights, badges, bullets, flechas): ~#5D8A22 / lima corporativo
- Verde claro de apoyo (dot-grid, fondos suaves): ~#E4EFC7
- Gris UI suave: #F2F4F7 / #D4D8DD
- Amarillo puntual (dato o badge secundario, uso mínimo): #FEBC2E
- Blanco sobre pills oscuras / highlights verdes: #FFFFFF

── TIPOGRAFÍA ──
Sans-serif moderna geométrica (Inter / Uni Neue / Helvetica Neue).
- Eyebrow / etiqueta: MAYÚSCULAS, tracking amplio, verde Desafío, tamaño pequeño
- Título: muy grande, Bold/Heavy, charcoal #0F1722; una frase clave puede ir dentro de un rectángulo redondeado verde con texto blanco (como “en digital.” en el sitio)
- Cuerpo: Regular, charcoal; negrita solo en 2–4 keywords clave
- Micro / badges: SemiBold, MAYÚSCULAS, verde

── COMPONENTES VISUALES DEL SITIO (aplicar a la slide) ──
1) Eyebrow verde arriba a la izquierda (ej. “FORMACIÓN DIGITAL · LATAM” o etiqueta de sección).
2) Headline grande con UNA frase destacada en pill/caja verde redondeada + texto blanco.
3) Párrafo corto con keywords en bold.
4) CTA estilo sitio: botón pill charcoal oscuro (“… →”) + link texto con flecha verde.
5) Foto o bloque visual a la derecha con esquinas redondeadas.
6) Detrás/al costado de la imagen: grilla de puntos verdes claros (dot-grid sutil).
7) Card flotante blanca sobre la imagen (caso / métricas): badge verde “CASO DE ÉXITO” o etiqueta similar; número grande (+1.000); 3 micro-métricas en fila; link “LEER MÁS →”.
8) Logo {desafío} latam_ (verde + negro) solo si corresponde al pie o esquina; tamaño pequeño.

── LAYOUT PREFERIDO (hero → slide) ──
Dos columnas ~50/50:
- Izquierda: eyebrow + título + cuerpo + CTAs
- Derecha: imagen redondeada + dot-grid + card de métricas superpuesta abajo

── PROHIBIDO ──
Fondos azul navy completos. Stock genérico de “tech abstract purple”.
Sombras múltiples / glow / glassmorphism exagerado.
Tipografía serif. Emojis. Watermarks. Más de un highlight-caja verde por slide.
Copiar textos del sitio si no corresponden al contenido de ESTA slide.

── CONTENIDO DE ESTA SLIDE ──
[PEGAR AQUÍ: título, subtítulo, bullets o métricas, número de slide]
```

## Cómo usarlo
1. Copiá el bloque completo.
2. Reemplazá la última sección con el contenido real de la slide.
3. Generá en Gemini / ChatGPT / diseñador manteniendo paleta + componentes.
