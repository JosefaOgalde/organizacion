# PRISA · Prototipo HTML (MKOF)

HTML basado en el Figma proto [prototipo_ prisa](https://www.figma.com/proto/qtDdatao4Vi4YY828rIYuH/prototipo_-prisa).

## Archivo
- `prototipo-prisa.html` — shell PRISA (header + nav + sidebar) + 2 vistas:
  - **Centro logístico / Cobertura Nacional** (tabla de zonas + click rutas)
  - **Retira cliente** (CEDIS Pudahuel, horarios, mapa, requisitos)

## Abrir
Con Laravel: `http://127.0.0.1:8000/index/clientes/MKOF/prisa/prototipo-prisa.html`

## Estimación para responder a MKOF / cliente
| Alcance | Tiempo orientativo |
|---|---|
| Maqueta HTML de 1–2 pantallas (como esta) | **4–8 h** (medio día–1 día) |
| Todo el prototipo Figma a HTML fiel (todas las pantallas del flow + assets reales) | **2–4 días hábiles** |
| HTML + responsive + QA pixel vs Figma + ajustes de copy legal | **+1–2 días** |
| Integración en sitio productivo (CMS / Magento / etc.) | aparte, según stack |

Respuesta corta sugerida:
> “Para pasar este Figma a HTML con la info de las pantallas de Centro logístico / Retira cliente: **aprox. 1 día** en maqueta navegable. Si es el prototipo completo pantalla a pantalla con assets y textos finales: **2 a 4 días hábiles**.”

## Nota
No se pudo usar Figma MCP (auth omitida). La maqueta se armó desde el proto público + textos PRISA públicos. Para pixel-perfect, autenticar Figma MCP o exportar assets del archivo.
