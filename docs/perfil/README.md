# Mi perfil · Josefa Ogalde

Espacio **personal** del organizador — **no es un cliente**.

| Qué | Dónde |
|-----|--------|
| Vista en la app | Organizador → pestaña **Mi perfil** (`?vista=perfil` o tab) |
| Datos en JSON | `perfilPersonal` en `data/organizacion-live.json` |
| Tarjeta / PDF | `index/assets/perfil/` |
| Postulaciones laborales | [`POSTULACIONES-LABORALES.md`](./POSTULACIONES-LABORALES.md) |

## Regla

- Encargos de **clientes** (TS, ECR, Tronwell, JM…) → carpeta / tarea del **cliente**.
- CV, cartas, postulaciones, portfolio personal → **Mi perfil** (esta carpeta + pestaña Mi perfil).
